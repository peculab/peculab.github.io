<p>沒有標準答案的程式語言課，鼓勵學生去向 AI 請教</p>

<p>只要課程設計與評分指標調整策略正確，就不需要防堵或害怕學生使用 AI 寫作業，而是讓學生透過 AI 學得更好</p>

<p>這學期在上程式語言時（for 初學者），搭配 LLM Python API 做了一些課程內容的調整，學生在練習所有單元主題時，所用到的資料，皆是學生參考我所寫的範例，去舉一反三帶入他們自行找到的資料進行替換，再對我提供的範例進行相對應程式段落的修改，並對自己的資料進行提問，透過程式分析後回答自己的提問</p>

<p>每一個小任務可以串成一個小專題，每一位同學都可以創造出屬於自己的小品集</p>

<p>1. 從 dataframe, set 認識資料型態，read csv 存入 dataframe 後，轉換型態成 set，進行資料的交集、聯集、差集，探索資料內容</p>

<p>2. 從 csv, json 認識檔案格式，read csv 存入 dataframe，read json 存入 dict，對資料提出三個問題，透過 plotly 繪製出相對應可回答問題的視覺化圖表</p>

<p>4. 使用 requests 發出 html 訪問請求，撈回網站內容後，透過 beautifulsoup 對 html 原始碼進行內文拆解，取出相對應的文字內容放置於 dataframe，輸出至 google sheet 中</p>

<p>5. 接續 4 所存在 google sheet 中的文字內容（作者與發文），透過 regular expression 進行基礎的資料清洗，再透過 jeiba 做斷詞將每位作者的發文前十大關鍵字挑選出來，建立作者與關鍵字的 Graph 關聯，最後用 networkx 將關聯圖繪製出來</p>

<p>6. 接續 5 的基礎流程，將 jeiba 做斷詞的部份抽換成 HuggingFaceHub，將 google sheet 中的每筆發文都丟向 Breeze-7B 進行摘要擷取、情緒分析、過濾重點特徵後，再重新繪製出關聯圖</p>

<p>7. 將 1 ~ 6 整併成一個完整的模組套件，再掛上 gradio 去生成網頁的使用者介面，變成期末專題</p>

<p>下禮拜會將範例程式 6 再分享出來</p>

<p>課程設計融合了實用的程式設計技能和 Python 開源套件，對學生來說，它能夠培養出以下能力：</p>

<p>1. 資料結構和型態的理解：透過操作 dataframe 和 set，學生可以深入理解資料結構的重要性和如何有效地操作它們以探索數據</p>

<p>2. 檔案格式和數據處理：通過處理不同的檔案格式（如 CSV 和 JSON），學生學會了如何讀取、處理和分析數據</p>

<p>3. 視覺化技能：使用 plotly 來繪製圖表，使學生能夠將複雜的數據集轉化為易於理解的視覺表示</p>

<p>4. 網路資料爬取與分析：通過 requests 和 beautifulsoup 進行網絡爬取和分析，學生學會如何從網路上自動收集數據並進行初步處理</p>

<p>5. 自然語言處理（NLP）基礎：透過 jeiba 和 HuggingFace 的應用，學生可學會基礎的文本處理技術，並瞭解如何快速駕馭 AI 開源套件</p>

<p>6. 圖論基礎與視覺化：透過 networkx 的使用，學生學會如何建立和視覺化複雜的網絡圖，這在社會網絡分析、推薦系統等領域非常重要</p>

<p>7. 模組化和最小可行性專題開發：將各個單元整合成一個完整的模組套件，並使用 gradio 建立使用者介面，學生能夠從中學習到模組化和軟體工程的基本原則，這對於開發可維護和擴展的系統至關重要</p>

<p>8. 實際應用與創新思維：課程鼓勵學生以創新的方式思考，並將所學知識應用於實際問題解決中，培養問題解決能力和創造力</p>
