<p>112-2 要開新課 - 網路輔助學習系統研究</p>

<p>為了不讓學生只是會用初淺的 UI 化 AI 工具，更希望學生能透過程式自創客製化的課程輔助系統，領略更深層的 AI 運用技巧，獲取更寬廣的科技應用實力。</p>

<p>在這門課程中，學生將學習如何使用 ChatGPT API、Python LangChain，以及 Hugging Face 提供的 API 來開發一個生成式 AI 學習輔助系統。本課程旨在幫助學生理解和掌握生成式 AI 技術的基本原理，並運用這些技術來創建創新且實用的教育應用程式。</p>

<p>課程內容將包括：</p>

<p>1. 生成式 AI 技術的基礎知識，包括其工作原理和應用範圍。<br>
2. 如何使用 ChatGPT API 進行語言模型的交互和應用開發。<br>
3. 利用 Python LangChain 進行數據處理和 AI 模型集成。<br>
4. 探索 Hugging Face 平台，學習如何利用其豐富的資源和工具來增強 AI 應用。<br>
5. 實際案例分析和動手實踐，讓學生能夠設計並實現自己的學習輔助系統。</p>

<p>透過本課程，學生將能夠深入理解生成式 AI 的強大功能，並掌握如何將這些技術應用於教育領域，創造出有助於學習和教學的創新工具。</p>

<p>大學部三年級以上，碩博士生，如果想要感受用程式語言駕馭 AI 的快感，歡迎來共學喔！</p>
